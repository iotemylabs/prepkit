Export

Offline HTML (e-ink)

A self-contained folder of plain pages — no scripts, no network access of any kind — sized for a 6-inch greyscale e-reader. Copy it onto the device or serve it from an offline node. Sensitive fields are excluded unconditionally; documents appear only if individually opted in.

Download offline export (.zip)

JSON

Standard export — conforms to inventory.schema.json. Serial numbers, costs, per-person needs, and location notes are stripped; documents appear only if individually opted in.

Full backup — restores the stripped fields and includes documents that did not opt in. Treat the file as confidential: it maps your valuables and your household. Identity, financial, insurance, and medical documents are never included, even here.

The same exports are available from the command line: prepkit export-static -o DIR and prepkit export-json.
