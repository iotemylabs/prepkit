Export

Offline HTML (e-ink)

A self-contained folder of plain pages — no scripts, no network access of any kind — sized for a 6-inch greyscale e-reader. Copy it onto the device or serve it from an offline node. Sensitive fields are excluded unconditionally; documents appear only if individually opted in.

Download offline export (.zip)

JSON

Standard export — conforms to inventory.schema.json. Serial numbers, costs, per-person needs, and location notes are always stripped; documents appear only if individually opted in.

Backup

Exports never carry serial numbers, costs, per-person needs, or location notes, and no switch restores them. A complete copy of your data is a database backup, made on the server with prepkit backup -o FILE. That file is unencrypted and holds everything, including identity documents, so store it as carefully as the instance itself.

The same exports are available from the command line: prepkit export-static -o DIR and prepkit export-json.
